# NEX UI Rules v1

## 1) General Principles
- ทุกหน้าต้องดูเป็นระบบเดียวกัน
- เน้นความชัดเจนก่อนความหวือหวา
- ใช้สีเพื่อสื่อ hierarchy ไม่ใช่เพื่อการตกแต่งอย่างเดียว
- ลดความซ้ำซ้อนของ CTA และ visual noise

## 2) Page Structure Rules
ทุกหน้าควรมีโครงสร้างที่ชัดเจน:
- Hero / Page Header
- Core content sections
- Supporting proof / benefit / feature
- Closing CTA

## 3) Heading Rules
- H1 ใช้สื่อสารคุณค่าหลักของหน้า
- H2 ใช้แบ่ง section
- H3 ใช้เป็นหัวข้อย่อยใน card หรือ feature block
- หลีกเลี่ยงการใช้ heading หลายระดับมั่วใน section เดียว

## 4) Button Rules

### Primary Button
ใช้สีส้ม `#F97316`
ใช้กับ action หลักของหน้า เช่น:
- สมัครใช้งาน
- ขอเดโม
- เริ่มต้นใช้งาน

### Secondary Button
ใช้โทนน้ำเงินหรือ outline
ใช้กับ action รอง เช่น:
- ดูรายละเอียด
- เรียนรู้เพิ่มเติม

### Tertiary Action
ใช้เป็น text link หรือ ghost button

หลักการ:
- 1 section มี Primary CTA เด่นได้ 1 ตัว
- อย่าให้ทุกปุ่มสีส้มพร้อมกันทั้งหมด

## 5) Card Rules
- ใช้พื้นขาวเป็นมาตรฐาน
- ใช้ border อ่อนหรือ shadow เบา
- radius ต้องสม่ำเสมอทั้งเว็บ
- headline ใน card ใช้ navy หรือ text primary
- อย่าใช้พื้นเข้มหลายใบติดกันถ้าไม่จำเป็น

## 6) Color Application Rules
- Navy = identity และ structure
- Orange = action และ emphasis
- Green = success และ support only
- Neutral background = ช่วยให้หน้าอ่านง่ายและดูแพงขึ้น

## 7) Form Rules
- label ต้องชัด
- field spacing ต้องสม่ำเสมอ
- focus state ใช้ navy หรือ info color
- success state ใช้ green
- error state ใช้ red
- ปุ่ม submit หลักใช้ส้ม

## 8) Navbar Rules
- ใช้ navy เป็นแกนหลักได้
- ต้องอ่านง่ายและ contrast ชัด
- CTA บน navbar ใช้ปุ่มส้มได้ 1 จุดหลัก
- อย่าใส่ปุ่มสีเด่นหลายตัวบน navbar

## 9) Section Rules
- แต่ละ section ควรตอบคำถามเดียวของผู้ใช้
- spacing บนล่างต้องสม่ำเสมอ
- ใช้ background alternating แบบพอดี เช่น white / light neutral
- หลีกเลี่ยง section ที่มีสีแรงติดกันหลาย section

## 10) Do / Don't

### Do
- ใช้สีตามบทบาท
- คุม visual hierarchy ให้ชัด
- ทำให้ CTA เด่นเฉพาะจุดสำคัญ
- ใช้ layout และ component ซ้ำอย่างมีระบบ

### Don't
- อย่าใช้ส้มเป็นสีหลักทั้งหน้า
- อย่าใช้เขียวเป็นสีเด่นเท่าปุ่ม CTA
- อย่าให้ทุก card คนละสไตล์
- อย่าใช้พื้นเข้มมากเกินไปจนเว็บดูทึบ
