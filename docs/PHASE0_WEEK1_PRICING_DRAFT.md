## 📈 Upgrade Path

### Free → Basic:
- **When**: User needs more than 3 pages/forms
- **Trigger**: "Upgrade" button when limit reached
- **Price**: ฿490/month

### Basic → Premium:
- **When**: User needs unlimited or custom domain
- **Trigger**: "Upgrade" button in settings
- **Price**: ฿1,990/month

### Downgrade:
- Users can downgrade anytime
- Downgrade takes effect at next billing cycle
- Content over limit is archived (can restore after upgrade)

---

## 🔄 Usage Limits & Overages

### Free Plan:
- **Over Limit**: Cannot create more (show upgrade prompt)
- **Leads Over Limit**: Oldest leads archived (can view but not export)

### Basic Plan:
- **Over Limit**: Cannot create more (show upgrade prompt)
- **Leads Over Limit**: Oldest leads archived (can view but not export)

### Premium Plan:
- **No Limits**: Unlimited everything

- **Free**: Get users in the door
- **Basic**: Main revenue driver (target 60% of paid users)
- **Premium**: High-value users (target 40% of paid users)

- Similar tools: ฿500-2,000/month
