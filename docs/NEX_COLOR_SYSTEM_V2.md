# NEX Color System v2

## 1) Brand Color Ratio
สัดส่วนการใช้สีแนะนำ:
- Primary Navy: 70%
- Orange Accent: 20%
- Green Support: 10%

## 2) Core Palette

### Primary Brand
- Primary: `#050579`
- Primary Hover: `#07079A`
- Primary Dark: `#03034F`

### Accent
- Orange Accent: `#F97316`
- Orange Hover: `#EA580C`

### Support
- Green Support: `#84CC16`
- Green Hover: `#65A30D`

## 3) Blue-Based Neutral Palette
- Background Main: `#EEF0FF`
- Background Alt: `#F6F8FF`
- Surface: `#FFFFFF`
- Surface Alt: `#E8ECFF`
- Border: `#D9E1F2`
- Divider: `#C7D2E5`

## 4) Text Colors
- Text Primary: `#0F172A`
- Text Secondary: `#475569`
- Text Muted: `#64748B`
- Text On Dark: `#FFFFFF`

## 5) Semantic Colors
- Success: `#16A34A`
- Warning: `#F59E0B`
- Error: `#DC2626`
- Info: `#2563EB`

## 6) Usage Rules

### Navy `#050579`
ใช้กับ:
- Navbar
- Headline หลัก
- Primary brand section
- Main icon treatment
- Primary UI emphasis
- Secondary option cards บน landing page

ไม่ควรใช้:
- พื้นเข้มต่อเนื่องหลาย section ยาวเกินไป
- card จำนวนมากในโทนเข้มพร้อมกัน
- text body ยาวบนพื้นเข้ม ถ้าไม่ได้จัด contrast ดีพอ

### Orange `#F97316`
ใช้กับ:
- Primary CTA
- Highlight สำคัญ
- Badge เน้นการกระทำ
- Active state บางจุด
- ปุ่มหลักเพียง 1 จุดเด่นใน gateway/landing

ไม่ควรใช้:
- เป็นสีข้อความหลักทั้งหน้า
- ใช้กับ element จำนวนมากในหน้าจนเด่นเกินไป

### Green `#84CC16`
ใช้กับ:
- Success state
- Positive metric
- Growth indicator
- Secondary highlight

ไม่ควรใช้:
- เป็นสีหลักของหน้า
- ใช้แทน CTA หลัก
- ใช้เยอะจนภาพลักษณ์ premium ลดลง

### Soft Blue Background
ใช้กับ:
- พื้นหลังหลักของเว็บไซต์
- hero แบบเรียบ
- landing page base tone
- section ที่ต้องการความโปร่งและทันสมัย

ไม่ควรใช้:
- เป็นสี card หลักแทนสีขาวทุกจุด
- ใช้จน contrast ของ content ต่ำลง

## 7) Recommended Pairings
- Soft Blue + White + Navy = โครงสร้างหลักของแบรนด์
- Navy + Orange = โทนขาย/CTA
- Navy + Green = โทนผลลัพธ์/การเติบโต
- Soft Blue Background + White Card + Navy Headline = มาตรฐานเว็บ NEX

## 8) Landing Page Recommendation
สำหรับหน้า landing/gateway:
- พื้นหลังหลักใช้ navy หรือ gradient navy-blue ได้
- container หรือพื้นที่รอบนอกใช้ soft blue ได้
- option box หลักใช้ navy
- ปุ่มหรือกล่อง action หลักใช้ orange เพียง 1 จุด
- card/content box ภายในใช้ white เมื่อต้องการเพิ่มความอ่านง่าย

## 9) Accessibility Notes
- ใช้ text สีขาวบนพื้น `#050579`
- ใช้ text สีเข้มบนพื้นขาวหรือพื้นอ่อน
- ปุ่ม CTA ต้องมี contrast ชัดเจน
- หลีกเลี่ยง text สีส้มบนพื้นขาวในขนาดเล็กมาก
