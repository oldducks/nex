# Page: Home Gateway

## Goal
ช่วยให้ผู้ใช้เลือกทางเข้าได้ทันทีภายใน 3-5 วินาที โดยคงภาพลักษณ์ของ NEX ให้เรียบ ชัด และเป็นมืออาชีพ

## Page Type
Minimal Gateway Landing Page

## Brand Direction
- Professional
- Trustworthy
- Modern
- Premium
- Focused
- Business-ready
- Clear

## UX Direction
- Minimal
- Fast to scan
- Mobile-friendly
- Logo-centered
- 4 clear choices only

## Structure
1. Centered logo
2. 4 option boxes
3. Minimal footer

## Primary Navigation Choices
1. เข้าสู่ระบบ
2. NEX คืออะไร
3. สมัครเป็น NEX Digital Agent
4. โซลูชันสำหรับองค์กร

## CTA Priority
- Primary highlight: เข้าสู่ระบบ
- Secondary: NEX คืออะไร
- Secondary: สมัครเป็น NEX Digital Agent
- Secondary: โซลูชันสำหรับองค์กร

## Copy Rules
- ใช้ข้อความสั้นและตรง
- ไม่ใส่คำอธิบายยาวใต้แต่ละช่อง
- หลีกเลี่ยงภาษาขายเกินจริง
- ทุก label ต้องอ่านแล้วเข้าใจได้ทันที
- แต่ละช่องควรจบใน 1 บรรทัดถ้าเป็นไปได้

## UI Notes
- โลโก้อยู่กึ่งกลางด้านบน
- ใช้ action boxes จำนวน 4 ช่องเท่านั้น
- ทุกช่องมีขนาดเท่ากัน
- มีช่องเด่นด้วย accent color ได้เพียง 1 ช่อง
- แนะนำให้ใช้สีส้มกับช่อง "เข้าสู่ระบบ"
- อีก 3 ช่องใช้ navy หรือ outline style
- พื้นหลังใช้ soft blue ตามระบบสี NEX
- card หรือ action box ใช้พื้นขาวหรือ navy ตามคอนเซปต์ที่เลือก
- spacing ต้องโปร่ง อ่านง่าย และไม่แน่น

## Recommended Color Usage
- Background Main: `#EEF0FF`
- Brand Navy: `#050579`
- Accent Orange: `#F97316`
- Support Green: `#84CC16`
- Surface: `#FFFFFF`
- Border: `#D9E1F2`
