# NEX Color System v1

## 1) Brand Color Ratio
สัดส่วนการใช้สีแนะนำ:
- Primary Navy: 70%
- Orange Accent: 20%
- Green Support: 10%

## 2) Core Palette

### Primary Brand
- Primary: `#050579`
- Primary Hover: `#07079A`
- Primary Dark: `#03034F`

### Accent
- Orange Accent: `#F97316`
- Orange Hover: `#EA580C`

### Support
- Green Support: `#84CC16`
- Green Hover: `#65A30D`

## 3) Neutral Palette
- Background: `#F8FAFC`
- Surface: `#FFFFFF`
- Surface Alt: `#EEF2FF`
- Border: `#E2E8F0`
- Divider: `#CBD5E1`

## 4) Text Colors
- Text Primary: `#0F172A`
- Text Secondary: `#475569`
- Text Muted: `#64748B`
- Text On Dark: `#FFFFFF`

## 5) Semantic Colors
- Success: `#16A34A`
- Warning: `#F59E0B`
- Error: `#DC2626`
- Info: `#2563EB`

## 6) Usage Rules

### Navy `#050579`
ใช้กับ:
- Navbar
- Headline หลัก
- Primary brand section
- Main icon treatment
- Primary UI emphasis

ไม่ควรใช้:
- ทั้งหน้าแบบพื้นเข้มทั้งหมด
- card จำนวนมากในโทนเข้มพร้อมกัน
- text body ยาวบนพื้นเข้ม ถ้าไม่ได้จัด contrast ดีพอ

### Orange `#F97316`
ใช้กับ:
- Primary CTA
- Highlight สำคัญ
- Badge เน้นการกระทำ
- Active state บางจุด

ไม่ควรใช้:
- เป็นสีข้อความหลักทั้งหน้า
- ใช้กับ element จำนวนมากในหน้าจนเด่นเกินไป

### Green `#84CC16`
ใช้กับ:
- Success state
- Positive metric
- Growth indicator
- Secondary highlight

ไม่ควรใช้:
- เป็นสีหลักของหน้า
- ใช้แทน CTA หลัก
- ใช้เยอะจนภาพลักษณ์ premium ลดลง

## 7) Recommended Pairings
- Navy + White = โทนหลักของแบรนด์
- Navy + Orange = โทนขาย/CTA
- Navy + Green = โทนผลลัพธ์/การเติบโต
- Light background + White card + Navy headline = โครงสร้างมาตรฐาน

## 8) Accessibility Notes
- ใช้ text สีขาวบนพื้น `#050579`
- ใช้ text สีเข้มบนพื้นขาวหรือพื้นอ่อน
- ปุ่ม CTA ต้องมี contrast ชัดเจน
- หลีกเลี่ยง text สีส้มบนพื้นขาวในขนาดเล็กมาก
