# NEX Brand Guideline v1

## 1) Brand Overview
NEX Solution คือแพลตฟอร์มดิจิทัลสำหรับธุรกิจ ที่เน้นความน่าเชื่อถือ ความทันสมัย และการใช้งานจริงในเชิงพาณิชย์

ภาพลักษณ์แบรนด์ที่ต้องการ:
- Modern
- Trustworthy
- Premium
- Business-ready
- Structured
- Clear

## 2) Brand Personality
แบรนด์ต้องสื่อสารในลักษณะต่อไปนี้
- มืออาชีพ แต่ไม่แข็งกระด้าง
- ทันสมัย แต่ไม่แฟนซีเกินไป
- ขายโซลูชัน ไม่ใช่ขายความซับซ้อน
- สื่อสารผลลัพธ์ให้ลูกค้าเข้าใจเร็ว

## 3) Tone of Voice

### ลักษณะข้อความ
- กระชับ
- ชัดเจน
- ตรงประเด็น
- เชิงธุรกิจ
- เน้นคุณค่าและผลลัพธ์

### สิ่งที่ควรเน้น
- ความน่าเชื่อถือ
- ความเป็นมืออาชีพ
- ความง่ายในการเริ่มใช้งาน
- การช่วยเพิ่มโอกาสทางธุรกิจ

### สิ่งที่ควรหลีกเลี่ยง
- คำโฆษณาเกินจริง
- ภาษาที่แฟนซีเกินจำเป็น
- ประโยคยาวและซับซ้อน
- การใช้หลายข้อความหลักในหน้าเดียวจนสับสน

## 4) Core Messaging Direction

### ข้อความหลักของแบรนด์
- แพลตฟอร์มดิจิทัลเพื่อยกระดับภาพลักษณ์และโอกาสทางธุรกิจ
- เครื่องมือที่ช่วยให้ธุรกิจดูน่าเชื่อถือ ทันสมัย และพร้อมเติบโต

### แนวข้อความที่ควรใช้ในเว็บ
- สร้างตัวตนธุรกิจให้ดูน่าเชื่อถือ
- เปลี่ยนการแนะนำธุรกิจให้ทันสมัยและใช้งานง่าย
- รองรับการใช้งานจริงสำหรับบุคคล ทีมขาย และองค์กร

## 5) Audience Direction
กลุ่มเป้าหมายหลัก:
- ธุรกิจ SME
- ทีมขาย
- ตัวแทน / Agent
- องค์กรที่ต้องการภาพลักษณ์ดิจิทัลที่เป็นระบบ

## 6) Visual Character
แนวทางภาพรวมของงานออกแบบ:
- ใช้โทนสีน้ำเงินเข้มเป็นแกนหลัก
- ใช้ส้มเพื่อดึง action
- ใช้เขียวอ่อนในบทบาท support เท่านั้น
- พื้นหลังต้องสะอาด โปร่ง อ่านง่าย
- ใช้ card, spacing, และ section ที่เป็นระบบ
- หลีกเลี่ยงสีเยอะเกินไปในหน้าเดียว

## 7) CTA Hierarchy
ลำดับความสำคัญของปุ่ม:
1. Primary CTA = สิ่งที่ต้องการให้ผู้ใช้กดมากที่สุดในหน้านั้น
2. Secondary CTA = ตัวเลือกเสริม
3. Tertiary CTA = link หรือ text action

หลักการ:
- 1 section ควรมี Primary CTA เด่นเพียง 1 ตัว
- อย่าให้ทุกปุ่มเด่นเท่ากัน
- CTA ต้องใช้ข้อความที่สื่อ action ชัด เช่น สมัครใช้งาน, ขอเดโม, ดูรายละเอียด

## 8) Consistency Rules
ทุกหน้าของเว็บไซต์ควรยึดหลักเดียวกัน:
- ใช้โทนข้อความเดียวกัน
- ใช้สีตามระบบเดียวกัน
- ใช้ component เดียวกัน
- ใช้ลำดับความสำคัญของ CTA เหมือนกัน
- หัวข้อหลักควรสื่อคุณค่า ไม่ใช่แค่คำสวย
